# STAT 110 Teaching

## Overview

This is the repository for my teaching material for Harvard's [Statistics 110](https://stat110.hsites.harvard.edu/), a course on probability. Each week will have a corresponding folder that contains the .tex file, rendered .pdf, and any necessary figures. Importantly, a "student" (no-solution) version can be attained by toggling the `\solutionsfalse` line in the .tex file.
